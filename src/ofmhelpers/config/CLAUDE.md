# config

Every env var is read here and nowhere else, and read at the call: no module keeps a `settings.<group>.<field>` from import (`tests/unit/config/test_settings_read_at_call_time.py`; the one exception is `web/main.py`'s session middleware).

- `settings.py` — one `BaseSettings` group per module (Session, Web, Infra, KieAI, Downloaders, Instagram, Accounts, Aigen, Higgsfield, Vault, GDrive, Logging).
- `VaultSettings.keys` (`OFM_VAULT_KEY`): comma-separated Fernet keys, first encrypts (db/encrypted.py). Lose them = lose every /phones login.
- `InfraSettings`: `OFM_ENV` (production|development, required: no default, so a deployment that does not say which it is does not start; the server's `.env` says production, `docker-compose.dev.yml` and `tests/conftest.py` say development), `POSTGRES_PASSWORD` (the default `database_url`'s password and compose's; fallback `ofmhelpers`), `OFM_FAKE_EXTERNALS` (every outside service faked: e2e), `OFM_FAKES_DIR` (fakes' cross-process state), `OFM_RQ_WORKERS` / `OFM_CLONE_LINKS_WORKERS` (5: the clone-links queue's own pool).
- `GDriveSettings` (`OFM_GDRIVE_*`): no folder id for the app: each owner's own Drive (Google sign-in), root found by name (`features/drive/folders.root_name()`, "DEV - " prefix outside production); POSTED folder name, day timezone, sweep interval, retries/timeouts. Service account key JSON (`SecretStr`, one line) + root folder id are only for the live Drive contract tests.
- `LinksSettings` (`OOPSIE_API_KEY_ADMIN`, `BOUNCY_API_KEY_ADMIN`, `OFM_LINKS_*`): admin fallback keys for /links, sync interval 3 h, claim/create TTLs, periods 1/7/30/90 d (default 7), page sizes, max links per Generate (100). See links/CLAUDE.md.
- `LLMSettings` (`LLM_DEFAULT_VIDEO` gemini, `LLM_DEFAULT_CHAT` groq, each `<provider>[:<model>]`; `GEMINI_API_KEY`/`GROQ_API_KEY`/`CEREBRAS_API_KEY` + `OFM_<PROVIDER>_MODEL`; `OFM_LLM_*` retries, timeouts, inline/image/contact-sheet limits): see llm/CLAUDE.md.
- `CloneAiCheckSettings` (`OFM_CLONE_AI_CHECK_*`: a still every 1 s, at most 16, 360 px, ffmpeg timeout, whole-check deadline 600 s, GLITCHY at >= 50%): see clone_ai_check/CLAUDE.md.
- `CloneLinksSettings` (`OFM_CLONE_LINKS_*`): links per paste (120), preview reads at once (6) and its deadline (90 s) / socket timeout, single-post extractors Check takes, review folders (`GOOD REELS`, `TRIAL REELS`), share-tracker params Check drops (`utm_*` = prefix), `REEL_MB` (Drive-room warning), halt TTL, review RQ limit (1200 s), a claimed review older than `REVIEW_STALE_S` (1800 s) = cut off and re-queued, up to `REVIEW_ATTEMPTS` (3).
- `PicturesSettings` (`OFM_PICTURES_*`: preset images max 10, pictures per submit 20, resolution 2K, aspect ratio 3:4): see web/routers/CLAUDE.md /pictures.
- `RunningHubSettings` (`RUNNINGHUB_API_KEY_ADMIN`, `OFM_RH_*`: base URL, request timeout, upload cache TTL 20 h (uploads are signed 24 h), reference image limits): see integrations/ai_providers/CLAUDE.md.
- `ElyumSettings` (`ELYUM_API_KEY_ADMIN`, `OFM_ELYUM_*`: base URL `https://api.elyum.ai`, request timeout, upload cache TTL 20 h, max file 60 MB, image side 8000, .mkv/.m4v convert timeout): see integrations/ai_providers/CLAUDE.md.
- `ApiyiSettings` (`APIYI_API_KEY_WAN` (or `APIYI_API_KEY` / `APIYI_API_KEY_ADMIN`) + `APIYI_API_KEY_SEEDANCE` + `APIYI_API_KEY_DEFAULT`: one key per APIYI token group, `apiyi/keys.py` picks per model; `OFM_APIYI_IMAGE_TIMEOUT_S` 600 (image calls answer in the request); `OFM_APIYI_MIN_POLL_INTERVAL_S` 5; `OFM_APIYI_*`: base URL `https://api.apiyi.com`, request timeout 180 s, link reuse 20 h, key check 1 h, Wan 3.0's file limits image 20 MB / video 100 MB / audio 15 MB; `OFM_APIYI_LINK_IMAGE_MAX_BYTES` 2 MB: the last-try JPEG copy of a linked image; `OFM_APIYI_SLOW_FROM_UTC_H` 11 / `OFM_APIYI_SLOW_UNTIL_UTC_H` 17: the hours the provider select warns it can be slow): see integrations/ai_providers/CLAUDE.md. `AigenSettings.raw_keep_s` (`OFM_AIGEN_RAW_KEEP_S`, 14 d) + `raw_sweep_s` (`OFM_AIGEN_RAW_SWEEP_S`, 1 d): raw provider downloads no job names, deleted (features/jobs/raw_files.py). `AigenSettings.unfetched_retry_waits_s` (`OFM_AIGEN_UNFETCHED_RETRY_WAITS_S`, 5/5/5 s): a request whose reference the provider could not fetch is sent again, the last time lighter (runner.generate). `AigenSettings.hosted_ttl_s` (`OFM_AIGEN_HOSTED_TTL_S`, 3 h) + `public_base_url` (`OFM_AIGEN_PUBLIC_BASE_URL`, unset = APP_BASE_URL): links to reference files a provider without uploads fetches (`ai_providers/hosting.py`).
- `WebSettings` /clone prices (dollars per source second = credits x $/credit): `OFM_CLONE_CREDITS_PER_VIDEO_S` + `OFM_KIE_USD_PER_CREDIT`, `OFM_CLONE_HF_CREDITS_PER_VIDEO_S` + `OFM_HF_USD_PER_CREDIT`, `OFM_CLONE_RH_USD_PER_VIDEO_S`, `OFM_CLONE_ELYUM_USD_PER_VIDEO_S`, `OFM_CLONE_APIYI_USD_PER_VIDEO_S` (JSON per resolution). `public_prefixes` default adds `/files/ai/`; `public_paths` has `/privacy` + `/terms` (routers/legal.py); `OFM_CONTACT_EMAIL` = the contact those pages show (empty: Telegram only).
- `ViralSettings` (`APIFY_API_KEYS` comma-separated -- the name the server's .env has held since the lead hunt; `OFM_VIRAL_*`: actor `apify~instagram-reel-scraper`, `SCAN` 200 newest reels read, `TOP` 30 kept, run timeout 900 s, download workers/timeout, Free-plan `USD_PER_REEL` 0.0026 / `USD_PER_RUN` 0.001 for the page's "up to $X"): see viral/CLAUDE.md.
- `EventsSettings` (`OFM_EVENTS_SENDERS_OFF` comma names, `KEY_TTL_S` 30 d, `RETRY_WAITS_S` [10, 60, 300]) and `TelegramSettings` (`OFM_TELEGRAM_BOT_TOKEN`, `OFM_TELEGRAM_CHAT_IDS`, API URL, timeout, `OFM_TELEGRAM_ASK_WAIT_S` 10 / `OFM_TELEGRAM_ASK_MAX_AGE_S` 300 for words typed to the bot): see integrations/senders/CLAUDE.md.
- `ReportsSettings` (`OFM_REPORTS_DAILY_ENABLED` true, `OFM_REPORTS_DAILY_AT` 14:00 on `OFM_REPORTS_TIMEZONE` Europe/Warsaw, `OFM_REPORTS_CHECK_S` 60): features/reports. `ChattingSettings.wait_events_check_s` (`OFM_CHATTING_WAIT_EVENTS_CHECK_S` 600): the "Chats unanswered" message every 10 min; `wait_recheck_poll_s` (`OFM_CHATTING_WAIT_RECHECK_POLL_S` 15): how often the rechecks due 5 min after each fan message (`features/chatting/rechecks.py`, planned from webhook and sync) are looked for; `events_platforms_off` (`OFM_CHATTING_EVENTS_PLATFORMS_OFF` "fanvue"): chat platforms left out of every chatting message to Telegram (unanswered list, daily mass messages), the site unchanged.
- `DownloadersSettings` retention (`OFM_DOWNLOADS_KEEP_UNUSED_S` 86400: a downloaded video no job used; `OFM_DOWNLOADS_KEEP_CLONED_S` 1209600: one a clone used, since its last use; `OFM_DOWNLOADS_KEEP_MAX_S` 2592000: any; `OFM_DOWNLOADS_SWEEP_S` 3600; `OFM_DOWNLOADS_SWEEP` unset = production only, `sweeping(production)`): features/downloads/cleanup.py.
- `WebSettings` VA control (2026-11-14, web/CLAUDE.md "VA control"): `OFM_VA_SESSION_MAX_AGE_S` 7200 (a VA's idle limit; everyone else keeps `SessionSettings.session_max_age_s`; here because the sweeps process reads it and has no session secret), `OFM_SEEN_WRITE_EVERY_S` 60 (`users.last_seen_at` written at most this often per person), `OFM_VA_IDLE_SWEEP_S` 60, `OFM_VA_REELS_NOTICE_EVERY` 10, `OFM_VA_SPEND_NOTICE_EVERY_USD` 10 (the owner's Telegram milestones).
- `SignInSettings` (`OFM_ADMIN_EMAILS`, `OFM_GOOGLE_CLIENT_*`, `OFM_APPLE_*`, password length/link TTL): see signin/CLAUDE.md.
- `__init__.py` — `from ofmhelpers.config import settings`; a group is rebuilt only when the process environment, its `env_file` or that file's mtime (checked at most every second) changed, so a test's `monkeypatch.setenv` applies immediately. Rebuilding on every access cost /reels 310 builds (~0.4 s) per request (prod profile 2026-10-22).

Use: `settings.<group>.<field>`.
