# config

Every env var is read here and nowhere else, and read at the call: no module keeps a `settings.<group>.<field>` from import (the one exception is `web/main.py`'s session middleware). Use `settings.<group>.<field>`; the groups, their fields and defaults are in `settings.py`.

- `VaultSettings.keys` (`OFM_VAULT_KEY`): comma-separated Fernet keys, first encrypts (db/encrypted.py). Lose them = lose every /phones login.
- `OFM_ENV` (production|development) is required, no default, so a deployment that does not say which it is does not start; the server's `.env` says production, `docker-compose.dev.yml` and `tests/conftest.py` say development. `OFM_FAKE_EXTERNALS` fakes every outside service (e2e); `OFM_FAKES_DIR` holds the fakes' cross-process state.
- `SESSION_SECRET` (`SessionSettings`): signs the session cookie and every other signed token (sign-in state, apply form, owner sign-in). Under 32 characters production refuses to start (`openssl rand -hex 32`); never the same value on dev and prod (a dev cookie would open prod). Changing it signs everyone out once. `SESSION_HTTPS_ONLY=true` on prod: the cookies go over HTTPS only.
- `OFM_DEBUG` (`InfraSettings.debug`, default off): FastAPI's debug mode for the web app; `docker-compose.dev.yml` sets it on the web service, production refuses to start with it. A bool: blank is not a value, the tests say `0`.
- `SentrySettings.dsn` (`SENTRY_DSN`, blank = off): ofmhelpers/monitoring/sentry.py. Release and environment on an event are `OFM_RELEASE` and `OFM_ENV`.
- `GDriveSettings`: no folder id for the app: each owner's own Drive (Google sign-in), root found by name (`features/drive/folders.root_name()`, "DEV - " prefix outside production). Service account key JSON (`SecretStr`, one line) + root folder id are only for the live Drive contract tests.
- `ApiyiSettings`: one key per APIYI token group (`APIYI_API_KEY_WAN` or `APIYI_API_KEY` / `APIYI_API_KEY_ADMIN`, `_SEEDANCE`, `_DEFAULT`), `apiyi/keys.py` picks per model. `OFM_APIYI_LINK_IMAGE_MAX_BYTES`: the last-try JPEG copy of a linked image. Image calls answer in the request. Details: integrations/ai_providers/CLAUDE.md.
- `AigenSettings`: `unfetched_retry_waits_s`: a request whose reference the provider could not fetch is sent again, the last time lighter (runner.generate). `hosted_ttl_s` + `public_base_url` (unset = APP_BASE_URL): links to reference files a provider without uploads fetches (`ai_providers/hosting.py`). `raw_keep_s`/`raw_sweep_s`: raw provider downloads no job names are deleted (features/jobs/raw_files.py).
- `CloneLinksSettings`: a claimed review older than `REVIEW_STALE_S` = cut off and re-queued, up to `REVIEW_ATTEMPTS`. AI check: features/clone_links/ai_check/CLAUDE.md.
- `WebSettings` /clone prices are dollars per source second = credits x $/credit (`OFM_CLONE_*`, `OFM_KIE_USD_PER_CREDIT`, `OFM_HF_USD_PER_CREDIT`; APIYI as JSON per resolution). `OFM_CONTACT_EMAIL` = the contact the /privacy and /terms pages show (empty: Telegram only).
- `WebSettings` VA control (web/CLAUDE.md "VA control"): `OFM_VA_SESSION_MAX_AGE_S` (a VA's idle limit; everyone else keeps `SessionSettings.session_max_age_s`) lives here because the sweeps process reads it and has no session secret.
- `ViralSettings`: `APIFY_API_KEYS` (comma-separated) keeps the name the server's .env has held since the lead hunt. See features/viral/CLAUDE.md.
- `ChattingSettings.events_platforms_off` (`OFM_CHATTING_EVENTS_PLATFORMS_OFF`): chat platforms left out of every chatting message to Telegram, the site unchanged.
- `DownloadersSettings` retention (features/downloads/cleanup.py): `OFM_DOWNLOADS_SWEEP` unset = production only, `sweeping(production)`.
- **Dev on a prod copy reaches no prod person by default (security audit 2026-11-18)**, the same tri-state: unset = production only. `OFM_EVENTS_SENDERS_OFF` (`EventsSettings.sending`: unset outside production = nothing is sent; `""` = every sender), `OFM_RECOVERY_RESTARTS` (`WebSettings.restarting`: cut-off local jobs started over; paid ones still resume), `OFM_DRIVE_SWEEP` (`GDriveSettings.sweeping`: the /drive sweep and /distribution's Drive reads; dev and prod share one Google client, so a copied token works). `tests/conftest.py` turns all three on for the suite.
- `POSTGRES_PASSWORD` and `REDIS_PASSWORD`: required by docker-compose.yml (no default since 2026-11-18), hex (`openssl rand -hex 32`), never the same on dev and prod. Each deploy makes the database user's password the .env value (`scripts/postgres_password.sh`), so a rotation is a .env change. `SESSION_HTTPS_ONLY=true` is required in production (refused to start otherwise).
- `SignInSettings`: see integrations/signin/CLAUDE.md. `LinksSettings`: integrations/short_links/CLAUDE.md. `LLMSettings`: integrations/llm/CLAUDE.md. `EventsSettings`/`TelegramSettings`: integrations/senders/CLAUDE.md. `PicturesSettings`: web/routers/CLAUDE.md /pictures. `RunningHubSettings`/`ElyumSettings`: integrations/ai_providers/CLAUDE.md.
- `__init__.py`: a group is rebuilt only when the process environment, its `env_file` or that file's mtime (checked at most every second) changed, so a test's `monkeypatch.setenv` applies immediately. Rebuilding on every access cost /reels 310 builds (~0.4 s) per request.
