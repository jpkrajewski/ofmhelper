# snapchat

Logged-out read of a public Snapchat profile for /accounts (`socials/platforms/snapchat.py`). Free, no login, no Apify (2026-11-21: every Snapchat Apify actor is a small third-party one and the page itself is enough).

- `client.py` `SnapchatClient(proxy).profile(username)`: GET `https://www.snapchat.com/@<user>` through `outbound.page_session(settings.snapchat, proxy)` (`OFM_SNAPCHAT_PROXIES`, `_TIMEOUT_S`, `_HTTP_RETRIES`; urllib3 retries 5xx). 404 = `SnapchatNotFoundError`, 429 = `SnapchatRateLimitedError`, other 4xx/5xx = `SnapchatUnavailableError`, no or unreadable `__NEXT_DATA__` = `SnapchatError` ("Snapchat changed its profile page").
- Page data (verified 2026-11-21 on kyliejenner, john, danewalkerjohn): `props.pageProps.userProfile` `$case` `publicProfileInfo` {username, title, subscriberCount (a string; rounded to hundreds on big accounts), profilePictureUrl, hostUserId = our account id}; `userInfo` = not a public profile, no numbers at all -> `SnapchatNotPublicError` (a lasting refusal on the row).
- Spotlight: `spotlightHighlights[i].storyId.value` pairs with `spotlightStoryMetadata[i]` (same index; empty slots have no storyId and uploadDateMs 0, skipped): `videoMetadata.uploadDateMs`, `thumbnailUrl`, views = `engagementStats.viewCount` (else `videoMetadata.viewCount`). Post url `/@<user>/spotlight/<storyId>`. The first page holds 16 slots. `complete` when `spotlightHighlightsCursor` is empty (every slot seen; else the scan reaches back to its oldest shown post); empty slots are counted as `hidden_posts` (owner 2026-11-21: "fix snapchat display"): /accounts shows the views of the shown ones plus "N hidden by Snapchat", never "—" for a period the shown ones cover. `subscriberCount "0"` = hidden (Snapchat's "Show Subscriber Count" is off by default): `followers_hidden`, the page says "Hidden", no growth or chart, not in Total followers. Lists of different length = refusal (never paired wrong); a slot without `videoMetadata` is skipped; a 200 page with no `userProfile` = not found.
- Logged out hides most of it (2026-11-21, owner's real numbers for @danewalkerjohn: 370 followers, 7 Spotlights 189 / 205 / 9.8k / 1.8k / 4.5k / 1.5k / 1.7k): the page has the 7 slots in that order but data on 2 only (9,765 and 4,468, rendered as the only 2 tiles), and `subscriberCount "0"` with the username where the count would be. Full numbers need a logged-in read: owner 2026-11-21, "keep it as is, no cookies": no logged-in Snapchat read, the hidden ones stay marked hidden. Stories' views are never public.
- `fake.py`: `www.snapchat.com` under OFM_FAKE_EXTERNALS: `fake_snap` (public, 3 Spotlights), `fake_hidden` (not public), anything else 404. Contract: `tests/contract/test_snapchat_contract.py` (real half under `live`: kyliejenner, teamsnapchat).
