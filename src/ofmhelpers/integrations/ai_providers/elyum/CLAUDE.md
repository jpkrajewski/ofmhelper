# integrations/ai_providers/elyum

## Elyum (`elyum/`, 2026-11-02)
- Public API `https://api.elyum.ai/v1` (docs elyum.ai/open/docs, /open/docs/mcp; `llms.txt`), `Authorization: Bearer ek_live_...`, key scopes `generate` + `spend`. One endpoint for every model: `POST /v1/generations {model, prompt, inputs[], duration, resolution, aspect_ratio, audio}` -> `g_...`, `GET /v1/generations/{id}` -> `status` queued/running (pending), succeeded (`outputs[].url`, signed 24 h), failed/canceled (`error {code, message}`: content_refused/timeout/generation_failed), `usage.usd`. Upload `POST /v1/files` (multipart `file`, PNG/JPG/WebP/MP4/MOV/WebM/MP3/WAV, 60 MB) -> `file_...` id, cached per account + path `OFM_ELYUM_UPLOAD_CACHE_TTL_S` (20 h; lifetime undocumented). Billed on delivery, failed/canceled free.
- `provider.wire_body`: the catalog's media fields (`image_urls`, `video_urls`, role from our `x-role`, default `reference`) become `inputs` `{role, file|url}` in field order; the rest goes as is; `@Image1`/`@Video1` in the prompt become Elyum's `@image1`/`@video1`. /clone: `CLONE_TARGETS["elyum"]` with `aspect=None` (no "adaptive" on Elyum: left out, the model follows the inputs).
- **Idempotency-Key** = our job key on every create: a resend returns the same generation (`Idempotent-Replayed`). Errors (`models.raise_for`, real HTTP status + envelope `error.code`): auth/scope = `ProviderAuthError`; insufficient_balance (402), key_cap/member_budget/client_budget (429) = `ProviderNoCreditsError` ("insufficient balance", card "No credits"); concurrency/rate_limited (429), model_unavailable/option_unavailable/maintenance (503, nothing charged) = `ProviderRateLimitError` (`retry_after`); other 5xx unavailable; else input. Unreadable 2xx = unavailable.
- Upload copies: .mkv/.m4v -> MP4 (`utils/video_mp4`, `OFM_ELYUM_VIDEO_CONVERT_TIMEOUT_S`), BMP/TIFF or over-limit images -> JPEG (`fitted`); anything else not taken, or over `OFM_ELYUM_MAX_FILE_BYTES`, = `ProviderInputError` before any call.
- `catalog.json` hand-made (no schema endpoint without a key): `alibaba/wan-3.0/reference-to-video` (up to 10 images + 5 clips; resolution 480p/720p/1080p default 1080p, duration 2-30 default 5, audio default true, aspect 16:9/9:16/1:1/4:3/3:4) and `alibaba/wan-3.0/text-to-video` (the contract test's cheapest: 480p 2 s ≈ $0.08). Wan 3.0 price $0.0396/$0.0792/$0.1584 per s of clip + output; "usually takes about 12 min".
- Key `ELYUM_API_KEY_ADMIN` (admins' default), `OFM_ELYUM_BASE_URL`. Fake `elyum/fake.py` (`FAKE_KEY`, `refuse_next` (status, code, message), `fail_next` (code, message), `created`, `uploads`); tests `tests/integration/aigenproviders/elyum/`, contract `tests/contract/test_ai_provider_contract.py`.
- Unverified until a real key runs: the reference-to-video model id (docs only spell out `.../text-to-video`; `GET /v1/models/alibaba/wan-3.0` with a key lists the tasks), whether prompt cites are case-sensitive, how long `file_...` ids live.
